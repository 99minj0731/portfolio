# 김민정 — Brand Designer Portfolio

서버 기능 없이 GitHub Pages에서 바로 사용할 수 있는 정적 포트폴리오입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 각 카테고리는 `categories` 아래의 독립 폴더로 구성되어 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**, `main`, `/ (root)`를 선택하고 저장합니다.
